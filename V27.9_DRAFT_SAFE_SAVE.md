# SpecsDekh v27.9 — Draft-Safe Phone Save

- Admin phone edits no longer fail only because a thumbnail or positive price is missing.
- When an incomplete phone is requested as `published`, it is saved safely as `draft`.
- The API returns the exact publication warnings.
- The editor stays open and shows an amber warning so the missing fields can be completed.
- Complete published phones continue to save normally.
- Public catalogue rules remain unchanged: incomplete drafts are not exposed publicly.
