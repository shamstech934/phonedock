# SpecsDekh v28.1 — SEO Monitoring & Submission

Added a lightweight admin SEO Monitoring Center with:

- Published phone indexability totals
- Valid slug, image and PKR price checks
- Empty active brand detection
- Canonical domain, sitemap and robots checks
- Google/Bing verification status
- Copy/open sitemap controls
- Direct Google Search Console and Bing Webmaster links
- Examples of published records needing SEO review

No paid API or AI dependency is required. Google Search Console remains the source of truth for actual indexing status.
