# SpecsDekh v31.11.0 — Unified Tracker Pipeline

This release consolidates operational tracking into one review-first pipeline.

Trackers included:
- Price Tracker (sources, verified listings, failures, stale checks, drops/increases)
- Specs Tracker (missing, incomplete and stale specifications)
- Image Tracker (missing and unverified images)
- Discount Tracker
- Discontinued Tracker
- Coming Soon / Launch Tracker
- PTA / Non-PTA / Unknown Tracker
- Data Quality Pipeline

No tracker invents data or automatically publishes unverified information. Every card links to the relevant admin workflow.
