# SpecsDekh Dynamic Homepage & Smart Filters

- Added a dedicated **Smart filters** tab in Homepage Builder Pro.
- Admin can manage price, RAM, storage, camera, screen, battery/connectivity filters.
- Homepage sidebar uses compact accordions; only one filter group opens at a time.
- Homepage price list defaults to six compact ranges while `/price-ranges` remains the detailed destination.
- Homepage years are data-driven and limited to six recent imported years.
- Screen-size links now pass `screenMin`/`screenMax` through the phones API.
- Existing saved homepage settings are preserved; new defaults are applied only when fields are missing.
