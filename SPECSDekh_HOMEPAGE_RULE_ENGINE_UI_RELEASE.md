# SpecsDekh Homepage Rule Engine & UI Release

- Homepage sections now use real admin section rules (automatic or manual).
- Empty categories can be hidden, so imported phones do not appear in unrelated sections.
- Trending is limited to recent phones and balances low/mid/high price tiers.
- Latest uses release date instead of import time where available.
- Popular brands can be limited to brands with published phones.
- Years are derived from imported phone data or a manual admin range.
- Homepage price ranges are fully editable and now cover Rs. 5,000 through above Rs. 600,000.
- All controls are available in Admin > Homepage Builder > Design/Sections.
