PhoneDock Price Tracking Error Fix
==================================

INSTALL
1. Extract this ZIP.
2. Open the extracted folder.
3. Copy its "src" and "scripts" folders into the ROOT of your current PhoneDock repository.
4. Choose Replace/Merge when Windows asks.
5. Commit and push the three replaced files to GitHub.
6. Wait for the Vercel deployment to finish, then hard-refresh /admin/price-tracker.

IMPORTANT
- Do not paste the outer patch folder into src.
- The destination root is the folder that contains package.json, src and scripts.
- No database records, environment variables, images or unrelated project files are included.

WHAT THIS FIXES
- API error details are no longer discarded by the frontend.
- A failed enable/disable action no longer hides the complete Phones table.
- Automatic mode is enabled only when a verified product listing exists.
- If verification is missing, the row remains visible and shows "Link required".
- The API explains that Auto-link catalog and Run sync now must verify the product link first.
