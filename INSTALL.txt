PhoneDock Card Status + Brand Lifecycle Patch
==============================================

Yeh full project ZIP nahi hai. Is mein sirf changed files hain, is liye size chhota hai.

Install:
1. Apne current GitHub project folder ka backup rakhain.
2. Is ZIP ko extract karein.
3. Extracted folder ke andar ka sara content apne PhoneDock project root mein copy karein.
4. Windows poochay to "Replace the files in the destination" select karein.
5. GitHub Desktop mein changes review karke commit aur push karein.
6. Vercel deployment complete hone ke baad hard refresh karein (Ctrl+F5).

Is patch mein:
- Phone cards par automatic Price drop / Price up indicators
- Price tracker ka current/previous price cards tak pohanchta hai
- Existing Trending, PTA, Non-PTA, Coming Soon, Rumoured aur Discontinued badges preserved
- Brand page tabs: All, Available / Latest, Rumoured, Coming Soon, Discontinued
- Main /phones page par global tabs: All Phones, Latest, Price Drops, Rumoured, Coming Soon, Discontinued
- Price Drops tab sirf genuine tracked old/new price discount walay phones filter karta hai
- Coming Soon tab announced, coming_soon aur legacy upcoming records ko safely include karta hai
- Tabs hamesha nazar aate hain; jis lifecycle ka database count zero ho us mein fake phone show nahi hota
- Old ?status=upcoming links backward-compatible
- Ranking cards ko bhi price/lifecycle tracker fields milti hain
- Regression test included
- Price Tracker ke legacy/missing percentChange records ab admin page ko crash nahi karte
- Missing percentage ya invalid numeric value par safe dash show hota hai
- Pehli detected price baseline hai; usay fake Price Increase list mein nahi dikhaya jata
- Recent Price Changes mein sirf valid old/new price wali genuine increase/decrease entries aati hain
- Price change ka source, date, status aur percentage API aur admin UI mein correctly map hota hai
- Baseline record per-phone History mein audit ke liye preserved rehta hai
- Phone row ka Enable switch ab waqai priceMode ko automatic karta hai
- Unlinked/untrusted phone par silent failure ki jagah clear setup message milta hai
- "Enable linked phones" trusted-source listings ko bulk mein automatic mode mein lata hai
- Explicit manual locks bulk operation mein preserve rehte hain
- Automatic mode tabhi lagta hai jab phone ke paas enabled trusted source ka product-page link ho

Automatic price data ka flow:
1. Sources tab mein source enabled + trusted hona chahiye.
2. Auto-link catalog product URLs ko phones se match karta hai.
3. Phones tab mein "Enable linked phones" dabayen.
4. Run sync now pehli verified price ko baseline banata hai.
5. Agli sync par price badlay to Price Drop/Price Up aur history automatically update hoti hai.

Lifecycle tabs ka data:
- Coming Soon, Rumoured aur Discontinued database ke availabilityStatus/release dates se aate hain.
- In records ko Admin Phones/Launch Center ya approved rumour feed se set karein.
- System fake lifecycle phones generate nahi karta; zero records hon to tab empty rehna correct hai.
